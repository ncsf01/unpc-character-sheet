# UNPC Character Sheet

Online character sheet for **The Officially Unofficial Ultimate No-Prep Challenge RPG** (UNPC RPG), created by Uriah Edwards.

🔗 **Live site:** https://ncsf01.github.io/unpc-character-sheet/

> **Legacy version:** the UNPC RPG has since been updated and renamed to *Free100 Simple RPG System*. This sheet is kept for the original rules.

## Features

- **Character manager**: save, load and delete characters in the browser, and download or upload them as JSON files
- **Portrait upload** from a file or an image URL
- **Skills** with specialization (+20 bonus)
- **Random character generator** 🎲
- **Strikes tracker** with character status
- **Dice roller** with difficulty modifiers, criticals and fumbles
- **Quick reference** for the system rules and magic
- **Dark mode** ☾

> Characters are saved in your browser's local storage, so they will be lost if you clear your browser data.
